What To Do Next

The current V2 outputs are functional, but this is still a small proof-of-concept dataset.

  1. Replace provisional labels with real disease outcomes or expert-reviewed labels.
  2. Add metadata like humidity, rainfall, trap area, and collection duration.
  3. Regenerate features and retrain so the risk model learns from biology, not just counts.
